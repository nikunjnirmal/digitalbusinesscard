One-time setup: let this page publish to your repository
  1. Create a GitHub access token. On that page:
    • Repository access: choose Only select repositories, then pick your card's repository.
    • Permissions: under Repository permissions, set Contents to Read and write.
    • Click Generate token and copy it.
  2. Paste it here:

Only remember it on your own phone or computer: anyone using this browser could change your card. The token can only edit this one repository. To revoke it, delete it in GitHub's token settings.

Or upload card.json yourself
  2. Open your repository's upload page, drag card.json onto it, and click Commit changes.
